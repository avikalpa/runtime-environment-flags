# AGENTS.md

## Mission

Maintain `@avikalpa/environment` as a tiny, dependable runtime-flag package for JavaScript environments.

## Boundaries

- Keep the API small and boring.
- Preserve compatibility across Node, browsers, workers, and unknown runtimes.
- Avoid adding convenience helpers that dilute the package's purpose.

## README And Release Notes Contract

- `README.md` should stay short: install, usage, runtime table, and caveats.
- Keep examples minimal and concrete.
- Changelog and release notes should focus on runtime-detection semantics, packaging changes, and compatibility guarantees users will care about.
- Release pages should reuse curated notes rather than autogenerated text.

## Release Notes Automation

- Keep `CHANGELOG.md` current with `## Unreleased` at the top while work is in flight.
- When cutting a release, move the user-visible notes into an exact version section before or during the tag workstream.
- Release automation should prefer the exact version section and fall back to `Unreleased` so curated notes still publish when the rename is late.
- Release pages should use curated changelog text rather than autogenerated notes.
- Keep release notes short and semver-relevant; this package wins by being predictable.
